Claude Code Plugin Varejo · ERP MIT

cd2tec / archeo-claude-plugins

Plugins para o Archeo MCP Creator, que conecta bancos de dados legados a assistentes de IA. Do banco legado ao painel executivo e às ferramentas de IA, com cada número conferido no seu banco.

  • add-mcp-tool: transforma uma pergunta de negócio em uma ferramenta MCP pronta, com SQL explorado, escrito e testado no banco conectado.
  • add-mcp-dashboard: painel executivo de varejo a partir do ERP/PDV, com KPIs, índice de saúde, rankings e curva ABC.
  • analyze-mcp-*: relatórios de estoque, vendas, compras, preços, perdas, fiscal, contábil e financeiro, cada um com conferência de reconciliação.
  • Somente leitura: SELECTs parametrizados e validados, nada é registrado automaticamente.

CLI · npm Claude Code MIT

nayamonia / wrapper-code

Rode o harness do Claude Code com outros provedores de LLM sem mexer na sua configuração. Criado por Gabriel Fernandes, fundador da CD2.

  • Launchers prontos para DeepSeek, Ollama, Qwen Cloud, OpenRouter, Kimi e Z.ai. O claude normal continua usando a Anthropic.
  • Configuração só para aquela sessão: nada é gravado em ~/.claude e nenhuma variável vaza para o seu shell.
  • Várias contas Claude lado a lado com --account e --temp (macOS e Linux).
  • wrapper-code usage: uso de tokens por provedor e modelo, medido localmente, sem guardar prompts.
Ver no GitHub npm
Node.js 18+ EN · PT · ES sem gateway
bash
# instale uma vez
$ npm install -g wrapper-code

# veja os provedores disponíveis
$ wrapper-code list

# abra uma sessão do Claude Code no DeepSeek
$ wrapper-code deepseek

# quanto você usou, por modelo
$ wrapper-code usage
